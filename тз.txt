# описание проекта

функционал телеграмм бота, вам нужно:

- человек нажимает /start в боте 

- бот говорит ему подпишись на канал и получишь подарок

- после подписки, бот выдает файл(подарок), если человек не подписан - не выдает

- если человек не подписался, бот ему напомнит(какой интервал ставить и сколько раз напоминалка должна быть?)

- есть команда для замены файла для лид магнита для админа
---------------------------------------------
# Стек:
- пайтон
- база postgres 16(запущена в докер,использовать другую схему и не трогать сущ. + redis(запущен в докер) (кеш,fsm сценарии))
- крон для напоминалки и проверки подписок
- докер упаковка
- полный слой логирования в терминале для отладки
- полинг, так как нет домена для вебхука
- что то для автоприменения миграций в к базе
- ведете git
